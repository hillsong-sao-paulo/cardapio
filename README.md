# Canteen menu

Counter, kitchen, and admin screens for a Hillsong São Paulo canteen or event. On screen the product word stays cantina.

## Run locally

Node.js and npm are required.

```sh
npm install
npm run dev
```

Open the URL Vite prints. The dev server listens on `http://127.0.0.1:8080`.

In development, a local demo database starts with the server. The terminal prints the admin login for that demo.

## Stack

- Vite
- TypeScript
- React
- shadcn/ui
- Tailwind CSS
